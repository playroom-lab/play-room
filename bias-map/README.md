## MAP types
各MAPは上下・左右の軸に加えて、四隅にタイプ名を表示する（写真が対角線に固まりにくいよう、2軸が別方向を測る組み合わせにしている）。
1. 推しタイプ MAP：上 近い / 下 遠い / 左 大人っぽい / 右 あどけない　四隅 彼氏・弟・国宝・天使
2. リアクション MAP：上 静 / 下 動 / 左 癒される / 右 心乱される　四隅 守りたい・しんどい・供給ありがとう・ギャップ沼
3. 沼 / 尊い MAP：上 熱い / 下 穏やか / 左 近づきたい / 右 拝んでいたい　四隅 沼・致死量・沼未満・尊い
4. CUSTOM：上下左右を自由入力
